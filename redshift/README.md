# Redshift

A night-time colour-temperature adjuster, and the one that matters most here — it runs in the primary X11 (BSPWM) session, warming the screen as the evening wears on.

Location is set manually, defaulting to Islamabad (lat/lon `33.6844` / `73.0479`). The day temperature sits at 6500K and eases down to 5000K at night, with gamma `0.8:0.7:0.8`.
