# Rofi themes (removed)

Bulk third-party `.rasi` themes were removed to shrink the repo.

**Primary launcher:** `launchers/ribbon/` (random style via `launcher.sh`; `styles/colors.rasi` is gitignored).

**Default `config.rasi`:** points at the ribbon theme for plain `rofi` invocations.

To add custom themes again, place `.rasi` files here or under `launchers/`.
