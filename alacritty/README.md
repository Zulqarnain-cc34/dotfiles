# Alacritty

The alternate terminal to Kitty — a GPU-accelerated emulator configured in a single [`alacritty.toml`](alacritty.toml), launching Zsh. Colours are defined inline rather than imported from a packaged theme; it runs `JetBrains Mono` across all four styles (regular, bold, italic, bold-italic), and has `live_config_reload` on so edits apply on save.
