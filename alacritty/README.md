# Alacritty

The alternate terminal to Kitty — a GPU-accelerated emulator configured in a single [`alacritty.toml`](alacritty.toml), launching Zsh. Colours are defined inline rather than imported from a packaged theme; it runs `JetBrains Mono` across all four styles (regular, bold, italic, bold-italic), keeps 10,000 lines of scrollback, pads the window by 4px, holds selected text out of the clipboard until an explicit copy, and has `live_config_reload` on so edits apply on save.
